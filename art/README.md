# Card art

One picture per card, named after the card id: `spongebob.jpg`, `aang.jpg`, `leo-rise.jpg`...

The `.jpg` files here are **stand-in portraits** drawn by code (`npm run portraits`, see `scripts/portraits/`).
To replace one with real anime art, upload an image with the same card id as a **`.png`**
(e.g. `spongebob.png`). A `.png` takes priority over the stand-in `.jpg`. Pictures uploaded to the
`main` branch's `art/` folder take priority over this branch.

Prompts and the full list of card ids: [docs/ART_PROMPTS.md](../docs/ART_PROMPTS.md).
